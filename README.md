# MusicAcernityWeb

A modern music web application built with **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, and **Aceternity UI**. The project focuses on delivering a clean, responsive, and interactive user experience with smooth animations and modern design principles.

---

## Features

- Modern and responsive user interface
- Built with Next.js App Router
- Reusable React components
- TypeScript for type safety
- Tailwind CSS for styling
- Aceternity UI components
- Framer Motion animations
- Optimized performance
- Mobile-friendly design

---

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Aceternity UI
- Framer Motion

## Getting Started

### Clone the repository

```bash
git clone https://github.com/asmitbiswas/MusicAcernityWeb.git
```

### Navigate to the project

```bash
cd MusicAcernityWeb
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Visit:

```text
http://localhost:3000
```
